# 📊 Sales Analysis Dashboard

## Project Overview

This project is an interactive Excel dashboard developed to analyze sales performance using Pivot Tables, Pivot Charts, and Excel formulas.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## KPIs

- Total Sales
- Total Orders
- Average Sales
- Profit Margin
- Peak Month

## Dashboard Features

- Sales Trend
- Sales by Region
- Sales by Segment
- Discount Analysis
- Shipping Analysis
- Profit Analysis
- Product Analysis
